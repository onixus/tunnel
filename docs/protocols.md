# Протоколы: установка, обновление и мониторинг из консоли

Раздел **«Протоколы»** единой консоли показывает три протокола — Hysteria 2,
TrustTunnel и **AmneziaWG 3.1**, — устанавливает и обновляет их из репозиториев
разработчиков и отображает состояние всех контейнеров и служб хоста.

Реализация проверена локально (см. «Проверка»); **на боевом сервере onixus-rf
установка и обновление из консоли ещё не выполнялись**.

## Порядок развёртывания

1. Разверните UI: портал `trusttunnel-web` (он же даёт вход администратора) и
   консоль — `python3 deploy/install-console.py` ([подробнее](../deploy/README.md)).
   Агент больше не требует заранее установленных H UI и каталогов протоколов.
2. Откройте «Протоколы», нажмите **«Проверить обновления»** — агент запросит
   версии в репозиториях разработчиков.
3. Установите нужные протоколы кнопкой **«Установить»**. Операции идут через общую
   очередь задач по одной и записываются в журнал.

## Источники и проверка подлинности

| Протокол | Репозиторий разработчика | Что загружается | Проверка |
|---|---|---|---|
| Hysteria 2 | [HyNetworks/hysteria](https://github.com/HyNetworks/hysteria) | `hysteria-linux-amd64` из релиза `app/vX.Y.Z` | SHA-256, опубликованный GitHub для файла релиза |
| TrustTunnel | [TrustTunnel/TrustTunnel](https://github.com/TrustTunnel/TrustTunnel) | `trusttunnel-vX.Y.Z-linux-x86_64.tar.gz`, из него `trusttunnel_endpoint` | SHA-256 файла релиза |
| AmneziaWG 3.1 | [amnezia-vpn/amneziawg-go](https://github.com/amnezia-vpn/amneziawg-go), [amneziawg-tools](https://github.com/amnezia-vpn/amneziawg-tools) | исходники по тегу `v3.1.*`, сборка в Docker | коммит тега, полученный при проверке версий; сдвинутый тег прерывает сборку; `go mod verify` |

Браузер передаёт только имя протокола и номер версии. Версия должна быть в
списке, полученном агентом из репозитория; URL, пути, образы и команды из
запроса не принимаются. Предварительные релизы и черновики не предлагаются,
понижение версии запрещено. Перенаправления при загрузке допускаются только на
`github.com` и `*.githubusercontent.com`. Хеш подтверждает соответствие файлу,
опубликованному разработчиком, и не заменяет аудит кода.

Готовые сборки Hysteria и TrustTunnel — только linux x86_64.

## AmneziaWG 3.1

- **Сервер:** контейнер `amnezia-awg` (образ `vpn-amneziawg:<версия>`), userspace
  `amneziawg-go`, UDP-порт задаётся при установке (по умолчанию 47443). Контейнер
  без `--privileged`: только `NET_ADMIN`, `NET_RAW` и `/dev/net/tun`.
- **Параметры 3.1:** при установке генерируются `Jc/Jmin/Jmax`, `S1–S4` (не менее 12 —
  требование защиты заголовков), непересекающиеся диапазоны `H1–H4` и
  `HeaderProtectionKey`. Они одинаковы на сервере и во всех клиентских конфигурациях
  и сохраняются при обновлениях. Клиенту нужна версия AmneziaVPN/AmneziaWG с
  поддержкой протокола 3.1.
- **Сеть:** туннель `10.8.1.0/24`, выход — напрямую с входного сервера. Клиентам
  запрещён доступ друг к другу и к приватным сетям (включая панели на хосте).
  Сервисная маршрутизация и локальный фильтр рекламы на AmneziaWG **не
  распространяются**; DNS клиента — `1.1.1.1, 1.0.0.1`.
- **Пользователи:** раздел «Пользователи» — создание, блокировка, смена ключей,
  экспорт `.conf` и QR, отправка конфигурации на e-mail/Telegram, счётчики трафика
  и время последнего рукопожатия. Изменения применяются `awg syncconf` без разрыва
  остальных сессий. Если перезагрузка списка не удалась, контейнер перезапускается,
  чтобы заблокированный или сменённый ключ не оставался действующим.
- **Состояние:** `/opt/amneziawg/state.json` (root, `0600`) содержит ключ сервера и
  ключи клиентов — они нужны для повторной выдачи конфигурации. Включите каталог
  в резервные копии. Docker публикует порт в обход части правил UFW; проверьте
  фактическую доступность UDP-порта.
- **Обновление:** образ пересобирается из исходников новой версии; прежний
  контейнер сохраняется до проверки нового и возвращается при ошибке.

## Hysteria 2

- **Обновление ядра:** загруженный бинарник заменяет управляемый H UI
  `/var/lib/h-ui/bin/hysteria-linux-amd64`. После запуска выполняется реальный
  запрос через текущий выход; при ошибке возвращается прежняя версия (копии — в
  `/opt/vpn-console/protocols/rollback`). Клиенты кратко переподключаются.
- **Установка с нуля** автоматизирует шаги 1–3, 5 и 7 [инструкции](hysteria-server.md):
  ядро и H UI 0.0.25 (закреплённый хеш из [versions](versions.md)), пользователь
  `hysteria`, каталоги, unit и bootstrap. Ядро остаётся **выключенным**: сертификат,
  выходы, GeoIP и конфигурацию ядра оператор настраивает в H UI. Установка
  отклоняется, если H UI уже есть или в `ufw status` нет запрета `8081/tcp` — сначала
  выполните `ufw insert 1 deny 8081/tcp`. Пароль администратора H UI сохраняется
  только в `/root/h-ui-bootstrap.json`.

## TrustTunnel

Endpoint живёт в образе портала. Установка и обновление собирают производный
образ `trusttunnel-web:endpoint-<версия>` поверх **текущего** образа контейнера,
заменяя только `/opt/trusttunnel/trusttunnel_endpoint`, — портал, адаптер сервисной
маршрутизации и данные не меняются. Перед переключением сохраняются compose и
копия SQLite. Проверяются `healthz`, версия endpoint и — для обновления
обязательно — протокольный probe `/opt/vpn-console/probes/trusttunnel`. При ошибке
возвращается прежний образ. Каждое обновление добавляет слой к образу. Остановленный
контейнер считается существующей установкой: для него доступно только обновление.

## Мониторинг

Таблица «Контейнеры» показывает все контейнеры Docker: образ, состояние,
healthcheck, число перезапусков, время запуска/остановки, код выхода и
опубликованные порты. «Службы хоста» — `h-ui`, агент консоли, Telegram-бот,
перехват DNS и Docker. Раздел обновляется каждые 15 секунд. Переменные окружения
и секреты контейнеров в браузер не передаются.

## Ограничения

- Операции с протоколами выполняются строго по одной; сборка AmneziaWG занимает
  несколько минут, остальные изменяющие операции агента в это время ждут.
- После аварийного выключения хоста во время установки восстановление ручное
  (сохранённые бинарник, compose, контейнер `*-previous`).
- Удаление протокола из консоли не реализовано.

## Проверка

`python -m pytest -q server/tests/test_protocols.py` — фиктивные GitHub и Docker,
временное состояние; без сети и боевых VPN. Дополнительно 3 октября 2026 вручную
на рабочей станции: образ собран из `amneziawg-go v3.1.20260828` и
`amneziawg-tools v3.1.20260812`, сервер запущен с параметрами запуска агента,
тестовый клиент с экспортированной конфигурацией установил рукопожатие и передал
трафик; релизы Hysteria 2.12.3, TrustTunnel 1.1.0 и H UI 0.0.25 загружены и сверены
с опубликованными хешами.
