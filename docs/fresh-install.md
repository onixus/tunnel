# Установка на пустой сервер

Нужен отдельный сервер **Ubuntu 24.04 x86_64**, минимум 2 CPU, 4 ГБ RAM,
15 ГБ свободного места, доступ root/sudo по SSH и Интернет для Ubuntu, Docker Hub,
crates.io и GitHub. ARM и обновление существующего сервера этим мастером не поддерживаются.
Для первой сборки Rust на 4 ГБ желательно 2 ГБ swap. Существующие каталоги VPN
и контейнеры мастер отклоняет. Рабочие серверы этим способом не переустанавливайте.

1. Загрузите `tunnel-installer-ubuntu24-amd64.run` и соседний `.run.sha256`
   на сервер (SCP или файловая панель хостинга).
2. В терминале сервера выполните:

   ```sh
   sha256sum -c tunnel-installer-ubuntu24-amd64.run.sha256
   sudo bash tunnel-installer-ubuntu24-amd64.run
   ```

   Один файл сам проверит вложенный архив и запустит мастер. Для ручной установки
   также поставляется `.tar.gz`: распакуйте и выполните `sudo bash deploy/install.sh`.

3. Введите публичный IPv4/домен сервера и e-mail для входа. Пароль генерируется
   автоматически. При нестандартном порте SSH укажите `--ssh-port ВАШ_ПОРТ`.
   Мастер устанавливает Docker, включает UFW, разрешает SSH, TrustTunnel 8443
   TCP/UDP, Hysteria 443 UDP и AmneziaWG 47443 UDP; блокирует H UI 8081 TCP.
4. После сообщения «Готово» выполните:

   ```sh
   sudo cat /opt/tunnel-installer/access.json
   ```

   Здесь логин, пароль, команда SSH и отпечаток сертификата. Сохраните в менеджер
   паролей. Не отправляйте этот файл другим людям.
5. **На своём компьютере** выполните команду `ssh` из файла (замените `root`, если
   входите другим пользователем), оставьте терминал открытым. Откройте
   **https://localhost:18443/admin/login**. Сертификат самоподписанный:
   сверьте SHA-256 отпечаток с `access.json`, затем разрешите его в браузере.
   HTTPS-вход доступен только через этот SSH-туннель.
6. Войдите и откройте **«Протоколы» → «Проверить обновления» → «Установить»**.
   Сначала установите нужный протокол, дождитесь окончания задачи, затем создайте
   пользователя и выдайте ему конфигурацию.

## Что требует дополнительной настройки

- **TrustTunnel:** после установки endpoint создайте пользователя, скачайте профиль.
  Сертификат сервера самоподписанный; используйте конфигурацию с CA из портала.
- **AmneziaWG:** стандартный порт 47443 UDP уже разрешён; при выборе другого порта
  откройте его в firewall хостинга и UFW. Для контейнера нужен `/dev/net/tun`.
- **Hysteria:** устанавливаются H UI и ядро, само ядро остаётся выключенным.
  Настройте сертификат и конфигурацию в H UI. Доступ к H UI — отдельный SSH-туннель
  `ssh -N -L 18081:127.0.0.1:8081 root@АДРЕС`; пароль в
  `/root/h-ui-bootstrap.json`. Выходы и GeoIP настраиваются по инструкции Hysteria.
- **VLESS/CDN:** установите Xray, затем «Настроить CDN». Нужен собственный домен
  с проксированием CDN. Откройте выбранный порт origin в firewall хостинга и UFW,
  желательно только для сетей CDN. Самоподписанный origin совместим с режимом Full;
  для Full (strict) нужен доверенный сертификат.
- Сертификат создаётся на **365 дней**, автоматического продления нет. До истечения
  замените сертификат/ключ в `/etc/letsencrypt/live/АДРЕС/`, перезапустите HTTPS
  контейнер и использующие сертификат протоколы, обновите CA у клиентов.
- Основной/резервный выход, Telegram, SMTP, подписанные обновления клиента и
  публичный HTTPS-домен панели настраиваются отдельно. По умолчанию выход прямой.

Docker публикует VPN-порты независимо от части правил UFW. Дополнительно ограничьте
доступ firewall хостинга; административные порты 18082, 18090, 18443 слушают loopback.

## Если установка остановилась

Исправьте указанную ошибку и повторите
`sudo bash tunnel-installer-ubuntu24-amd64.run --resume`. Для распакованного архива:
`sudo bash deploy/install.sh --resume` из того же каталога. Настройки и пароль сохраняются в
`/opt/tunnel-installer/settings.json` с доступом только root. Мастер не удаляет данные
и не откатывает пакеты ОС/firewall автоматически. Отмеченный файл `complete`
означает окончание установки UI, а не проверку подключения VPN с вашего устройства.

## Сборка архива разработчиком

```sh
python3 scripts/build-installer.py --client-source /путь/к/R-Trusttunnel
```

Архив содержит исходники этой рабочей копии и client codec по закреплённому коммиту
`4400ca12938619df92326c4abe21818bf39915e9`. `manifest.json` хранит SHA-256 файлов,
HEAD сервера и SHA клиента. Образы ОС и транзитивные зависимости загружаются при
установке; архив не является полностью offline или воспроизводимой бинарной сборкой.
