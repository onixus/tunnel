# Панели и пользователи

## Вход в консоль

Для свежей установки используйте SSH-команду и данные из
`/opt/tunnel-installer/access.json`, затем откройте
`https://localhost:18443/admin/login`. Сверьте отпечаток сертификата.
Для публичного HTTPS-входа используйте настроенный вами домен, например
`https://vpn.example.com/console/`. Вход выполняется администратором TrustTunnel;
`/admin/dashboard` перенаправляет в консоль.

[Возможности консоли](unified-console.md) · [Гайд установки](installation.md).

## Прямой доступ для диагностики

На своём компьютере, заменив домен и SSH-порт:

```sh
ssh -N -o ExitOnForwardFailure=yes \
  -L 127.0.0.1:18081:127.0.0.1:8081 \
  -L 127.0.0.1:18082:127.0.0.1:18082 root@vpn.example.com
```

H UI после установки: `http://127.0.0.1:18081/`.
Портал: `http://127.0.0.1:18082/admin/login`.
Адреса работают только на компьютере с активным туннелем. Если локальный порт
занят, выберите другой. HTTP защищён SSH на участке между клиентом и сервером.
Публично эти административные порты не открывайте.

Для доступа через Hysteria необходимы явные правила ACL и маршрут клиента
к приватному адресу панели. Пример использует `10.254.77.1`, но этот адрес
не создаётся автоматически для любого развёртывания. SSH работает независимо
от таких правил VPN.

## Данные доступа

Мастер сохраняет первый вход в `/opt/tunnel-installer/access.json`.
Bootstrap H UI сохраняет пароль в `/root/h-ui-bootstrap.json`.
Файлы доступны только root; храните актуальные данные в менеджере паролей.
Пароль панели, VPN-пароль, salamander и SOCKS-пароль — разные секреты.
После ротации старые копии могут быть неактуальны.

## Пользователи

В консоли создайте человека, добавьте необходимые протоколы, выдайте отдельные
ключи и профили. Учётные записи разных протоколов не объединяются по совпадению
имени. Пользовательский кабинет TrustTunnel показывает собственные профили;
публичная регистрация по умолчанию выключена. H UI позволяет задать срок,
квоту и число устройств. Проверяйте экспорт на одном клиенте до массовой выдачи.

Блокировка и ротация могут переподключать другие VPN-сессии; см.
[политику применения credentials](device-credentials.md). Наличие HTML панели
не подтверждает работу endpoint. Для диагностики используйте состояние консоли,
`docker top`, сокеты и сквозной запрос, а не отдельный процесс Python с новым
экземпляром `endpoint.manager`.

## Утрачен доступ

Сначала восстановите SSH и сделайте согласованную копию данных. Не отключайте
авторизацию панели. Для H UI используйте процедуру сброса своей версии при
остановленном сервисе. У портала есть `scripts/manage_admins.py`; начните с
`--help` внутри контейнера. Не публикуйте вывод с секретами.
