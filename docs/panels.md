# Панели и пользователи

| Панель | Через SSH на рабочем компьютере | Через Hysteria | Администратор |
|---|---|---|---|
| H UI | http://127.0.0.1:18081 | http://10.254.77.1:8081 | `sysadmin` |
| TrustTunnel | http://127.0.0.1:18082/admin | http://10.254.77.1:18082/admin | `admin@onixus.ru` |

Команда для обоих SSH-туннелей приведена в [README](../README.md). HTTP защищён SSH или Hysteria на участке от клиента до сервера. Не открывайте порты панелей в интернет без отдельного HTTPS-прокси и проверки модели доступа.

На сервере H UI администраторские данные сохранены в `/root/h-ui-admin.json`; TrustTunnel — `/opt/trusttunnel-web/access.json`. Доступ к этим файлам — только root. При новой установке bootstrap-файлы могут иметь другое имя, см. инструкции. Старые сохранённые пароли могут стать неактуальны после ротации.

## H UI

Выберите русский язык на странице входа. Создайте отдельного пользователя VPN, задайте connection password, срок, квоту и лимит устройств по задаче. Проверьте экспорт на одном клиенте с доверенным сертификатом до массовой раздачи. Не изменяйте `existing-clients`, пока устройства с общим старым профилем не мигрировали.

Статистика и онлайн-пользователи поступают от локального trafficStats ядра. Если UI открыт, но клиенты не подключаются, отдельно проверьте процесс Hysteria и его UDP 443 — наличие HTML панели не является health-check VPN.

## TrustTunnel

Админка `/admin`: пользователи, блокировка, настройки endpoint, администраторы. Пользовательский кабинет `/`: собственные профили и скачивание TOML. Учётная запись портала и учётные данные VPN разделены. Открытая регистрация выключена.

Блокировка исключает VPN credentials пользователя и перезапускает endpoint; остальные пользователи кратковременно переподключаются. Изменение порта/домена должно сопровождаться проверкой сертификата, Docker port mapping и клиентских профилей.

Сторонние Windows/Android установщики панели не установлены; используйте официальные клиенты. Привязка по QR через отдельный portal device API не проходила проверку. Проверены входы в оба кабинета, TOML и официальный экспорт deeplink.

Нельзя проверять живой `endpoint.manager.status()` отдельным `docker exec python`: это другой процесс, у которого нет дескриптора запущенного дочернего endpoint. Смотрите dashboard, `docker top`, реальные сокеты и сквозной запрос через клиент.

## Утрачен доступ

Сначала восстановите SSH и резервную копию. Не отключайте авторизацию панели. H UI: остановите сервис, сделайте SQLite backup и используйте процедуру сброса для зафиксированной версии/официальную документацию. TrustTunnel содержит `scripts/manage_admins.py`; посмотрите `--help` внутри контейнера. Пароли не передавайте как аргументы shell на общей системе и не публикуйте вывод с секретами.
