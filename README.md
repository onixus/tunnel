# Tunnel: серверы, клиенты и эксплуатация

Серверная часть Tunnel: портал TrustTunnel, единая VPN-консоль, агент управления
и установщики для Ubuntu 24.04 и CentOS Stream 9/10 x86_64.

**Новый сервер:** [гайд по установке](docs/installation.md) — подготовка пакета,
первый вход, установка протоколов и проверка подключения.
**Существующий портал:** [установка консоли](deploy/README.md).

Адреса `vpn.example.com`, `exit.example.com`, `reserve.example.com` и сети
`192.0.2.0/24`, `198.51.100.0/24`, `203.0.113.0/24` в документации — примеры.
Замените их своими значениями. Приватные подсети, интерфейсы и порты также
нужно сверять с конфигурацией своего сервера. `REPLACE_LOCALLY_*` обозначает
секрет или параметр, который задаётся локально.

## Возможности

Единая консоль использует учётную запись администратора портала TrustTunnel.
Она управляет пользователями, ключами и устройствами, сроками/лимитами Hysteria,
выходами, обновлениями, черновиками рассылок, очередью задач и аудитом.

| Протокол | Стандартный вход | Дополнительная настройка |
|---|---|---|
| Hysteria 2 | 443/UDP | Сертификат и ядро в H UI |
| TrustTunnel | 8443/TCP+UDP | Пользователь и профиль с корректным TLS-доверием |
| AmneziaWG 3.1 | 47443/UDP | Клиент с поддержкой 3.1 |
| VLESS через CDN | HTTPS CDN; отдельный origin-порт | Собственный домен и CDN |

Карта маршрутов выбирает общий, закреплённый или прямой выход для каждого
протокола. Системный трафик сервера сохраняет свой маршрут. На свежем сервере
сначала устанавливается UI, затем выбранные протоколы; выход по умолчанию прямой.
Основной и резервный узлы настраиваются отдельно. Автоматический failover
не реализован. Учётные записи разных протоколов связываются явно в карточке
человека. Рассылки требуют согласия получателей и подтверждения отправки.

## Доступ администратора

Мастер новой установки публикует HTTPS-панель только на loopback. После установки
прочитайте `/opt/tunnel-installer/access.json` на сервере и выполните SSH-команду
из него на своём компьютере. Затем откройте `https://localhost:18443/admin/login`
и сверьте отпечаток сертификата. Подробности — в [гайде](docs/installation.md#4-откройте-консоль).

Для существующего развёртывания используйте настроенный вами HTTPS-домен
с путём `/console/` либо [SSH-туннель](docs/panels.md). Пароли и ключи храните
вне Git. Не применяйте весь каталог примеров поверх рабочей конфигурации.

Локальная проверка ссылок, JSON-шаблонов и маркеров секретов:

```sh
python3 scripts/validate-docs.py
```
